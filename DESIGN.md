# Design tokens (Docsense family)

Reuse the **Docsense deep green + gold** system. Do not use the ink/orange cover palette for product UI.

| Token | Hex | Role |
| --- | --- | --- |
| `--ink` | `#17261E` | Darkest green / text on light / gold contrast |
| `--panel` | `#1E3328` | Dark panels |
| `--faint` | `#2E4739` | Borders, faint fills |
| `--soft` | `#5E7A69` | Secondary strokes / muted labels |
| `--muted` | `#A9B8AD` | Muted text |
| `--line` | `#C9D6CB` | Hairlines |
| `--paper` | `#EEF2EC` | Light background / cream |
| `--gold` / accent | `#E3C77A` | CTA, focus, highlights |
| Light body | `#3D5648` | Body copy on paper |
| Dark bg | `#0F1A14` | Dark mode page |
| Dark card | `#1A2B22` | Dark mode surface |
| Dark body | `#B7C4BA` | Dark mode body |

Canonical CSS: `apps/web/src/styles.css`.
Source of truth in Docsense: `examples/docusaurus-site/src/css/custom.css`.
